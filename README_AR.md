# SAYYAR — سيّار

مصدر محدث لتطبيق ملاحة عراقي بواجهة داكنة بنفسجية واسم ظاهر **SAYYAR**.

## الملفات المهمة
- `lib/main.dart`: واجهة التطبيق ومنطق البحث والمسار والصوت.
- `assets/sayyar_icon.png`: أيقونة SAYYAR.
- `pubspec.yaml`: المكتبات وإعدادات الأيقونة.
- `.github/workflows/build-apk.yml`: بناء APK تلقائياً على GitHub Actions.

## الرفع عبر متصفح GitHub
ارفع محتويات هذا المجلد إلى جذر المستودع مع الحفاظ على المسارات، خصوصاً `.github/workflows/build-apk.yml` و`lib/main.dart` و`assets/sayyar_icon.png` و`pubspec.yaml`. بعدها افتح Actions وانتظر `Build SAYYAR APK`، ثم نزّل Artifact باسم `SAYYAR-APK` عند نجاح البناء.

## التغييرات
- طلب صلاحية الموقع عند أول تشغيل.
- خريطة داكنة بنفسجية من CARTO مع إمكانية التبديل إلى OpenStreetMap.
- فصل موقع GPS عن الوجهة لتجنب المسار الذي يبدأ وينتهي في نفس المكان.
- حساب مسار طرق من OSRM ورسم هندسة الطريق الفعلية.
- إرشادات عربية صوتية مع تقدير المسافة والوقت وتقدم الخطوات حسب GPS.
- إنشاء أيقونة Android واسم التطبيق `SAYYAR` أثناء البناء.

## حدود النسخة
تحتاج الخرائط والبحث والمسارات إلى الإنترنت، وتعتمد المسارات على خدمة OSRM العامة وقد تتوقف مؤقتاً. الصوت يعتمد على محرك النطق العربي في الهاتف. بيانات الازدحام الحي والتقارير المجتمعية الحقيقية غير مفعلة في هذه النسخة.
